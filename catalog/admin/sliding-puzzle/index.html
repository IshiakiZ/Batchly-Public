HOW TO PLAY

SLIDE THE TILES INTO ORDER

One square is empty. Tap or click any tile in the same row or column as the gap and the whole run of tiles between it and the gap slides across. Order the tiles 1, 2, 3… left-to-right, top-to-bottom, with the gap in the bottom-right corner.

  • Sizes. 3×3 (8 tiles), 4×4 (the 15-puzzle) and 5×5 (24 tiles).
  • Two skins. Numbers shows the tile numbers; Image paints a gradient picture across the tiles; assemble it, and the missing corner fills in when you win. A faint number stays in the corner to help.
  • Moves count every tile that slides, so a three-tile line-slide counts as three. Time starts on your first slide.
  • New deals a fresh scramble; Reset returns the current board to its start.
  • Every board is generated by scrambling a solved board with real slides, so it is always solvable, never a dead end.

Keyboard: ←↑↓→ slide a tile into the gap (the arrow is the way the tile travels) · N new · R reset · M switch skin · Esc close
