HOW TO PLAY

A famous quote has been scrambled with a secret code: every letter has been swapped for another one, the same way every time. Your job is to break the code and read the quote.

  • Pick a code letter: click any coded cell, or tap its chip in the frequency strip. The small letter under each blank is the code.
  • Type its real letter: use your keyboard or the on-screen keys. Every cell with that same code fills in together.
  • Frequency helper: the strip shows how often each code appears, commonest first. In English, E T A O I N lead; match your top codes to those to get started.
  • No letter is its own code, so a code never stands for itself.
  • Amber warns you used one real letter for two different codes: a real solution uses each letter once.
  • CHECK marks filled cells green / red against the answer. HINT locks in one correct blue letter. NEW deals a fresh puzzle; CLEAR wipes your guesses.

Keys: letters type · Backspace deletes · arrows move · space skips ahead.
