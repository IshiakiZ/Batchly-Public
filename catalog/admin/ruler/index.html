Ruler

 

Lay the object along the scale with one end flush against the red 0 line at the very start. Centimetres run along one side, inches along the other. This page sits inside a frame, so the object cannot hang off the edge of the screen; for anything awkward, use Measure and put a marker at each end.

Drag the two markers to the ends of the object lying on the screen. Two fingers work at once, one on each marker.

-

Arrow keys nudge a focused marker by 1 mm, Shift+Arrow by 1 cm, Home / End jump to the ends.

Why this step exists

A browser has no idea how big your screen physically is. A CSS pixel is a unit of layout, not of length, and devicePixelRatio only describes rendering density, not size. The only way to get real millimetres is to show you a line and have you match it to an object whose size is known. Everything this app reports is exactly as accurate as this one measurement.

No reference object? Estimate from screen size

If you know your display's advertised diagonal, this gets you close. It is an estimate: advertised diagonals are rounded, and on a desktop it is wrong if the browser is zoomed. Matching a real object is always better.
