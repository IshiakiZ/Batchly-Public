HOW TO PLAY

MATCH THE CLUES · REVEAL THE PICTURE

Each number is the length of a run of filled cells, in order. A row clue 3 1 means a run of three, then a gap, then a run of one, somewhere along that row. A 0 means the line is empty.

filled marked empty (a note to yourself)
  • Left-click / tap fills a cell. Right-click / long-press marks it with an ×: empty cells you've ruled out. Marks are just notes; only filled cells count.
  • Drag to paint a straight line of the same action. The first move locks it to a row or column.
  • The Fill / Mark toggle picks what a plain tap does; handy on a phone. The other action is always one long-press away.
  • Finish a line correctly and its leftover cells are auto-crossed for you, and its clue numbers dim.
  • Assist flags a filled cell that doesn't belong in red. Turn it off for an unaided solve. Hint reveals one true cell.

Keyboard: ←↑↓→ move · F/Space fill · X mark · N new · R reset · H hint · Esc close

Every board is a random picture whose clues have exactly one solution, verified by a logic solver during generation, so a board is always fully solvable by deduction, never by guessing.
