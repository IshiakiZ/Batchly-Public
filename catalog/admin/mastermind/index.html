HOW TO PLAY

CRACK THE HIDDEN CODE

A secret code of 4 pegs is hidden behind the top row. Build a guess from the six colours below and press CHECK. You have 10 guesses.

Each colour also has its own shape so the game is fully playable without colour vision:

After every guess the small pegs on the right report how close you were, but not which peg is which:

Exact: right colour & right spot
Colour: right colour, wrong spot
  • A peg is only ever counted once. Two exact/colour pegs never point at the same secret peg, so the feedback total is never more than 4.
  • Dupes: On lets the code repeat colours. Off makes the code four distinct colours. Your own guesses may always repeat.
  • No luck, pure deduction: the code never changes once dealt.

Keyboard: 1–6 place a colour · ←→ move cursor · ⌫ delete · Enter check · N new · Esc close
