HOW TO PLAY

TURN EVERY LIGHT OFF

Press any tile and it flips, along with the tiles directly above, below, left and right of it. Clear the whole board in as few moves as you can.

  • PAR is the fewest moves that can possibly clear the board you were dealt. Matching it is an optimal solve.
  • Hint reveals one tile from an optimal press-set. Solve rings all of them.
  • Using a hint or Solve marks the board assisted, and an assisted solve will not set a new BEST.
  • Order never matters: a solution is a set of tiles, not a sequence. Pressing the same tile twice undoes it.
  • Every board is generated by pressing tiles on a solved board, so a board is always solvable, never guesswork.

Keyboard: ←↑↓→ move · Enter/Space press · N new · R reset · U undo · H hint · S solve · Esc close

PAR and the hints are not guesses: the board is solved as a linear system over GF(2), and the shortest press-set is found exactly by minimising over the toggle matrix's nullspace.
